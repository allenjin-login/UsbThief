详细设计: 方案 A — 动态托盘图标

第二部分：系统托盘行为与动态图标

托盘图标状态

空闲

灰色 USB 图标
无设备活动

扫描中

绿色图标 + 放大镜
发现新设备扫描文件

复制中

蓝色图标 + 下载箭头
速度越快箭头颜色越亮

错误

红色图标 + 感叹号
复制出错或设备异常

托盘图标实现方式

使用 Java 2D 动态生成 BufferedImage作为托盘图标：

  • 预生成4种状态的 16x16 / 32x32 图标（适配 DPI 缩放）
  • 根据 EventBus 事件（DeviceEvent / CopyEvent）切换图标状态
  • 复制中时可在图标右下角叠加小箭头或速度指示器
  • 图标切换通过 SystemTray.getTrayIcon().setImage() 实现
